## 🗂️ 파일 구조 분석

### 파일 목록 및 크기

| 파일명 | 크기 | 형식 | 설명 |
|--------|------|------|------|
| `index.faiss` | 94 KB | Binary | FAISS 벡터 인덱스 |
| `index.pkl` | 32 KB | Pickle | LangChain 메타데이터 |
| `metadata.tsv` | ~5 KB | TSV | 문서 메타데이터 |
| `vectors.tsv` | ~500 KB | TSV | 벡터 임베딩 데이터 |

### 각 파일 포맷 상세 설명

#### 1. **index.faiss** (FAISS Binary Index)
- **포맷**: Facebook AI에서 개발한 벡터 검색 라이브러리의 바이너리 형식
- **특징**: 
  - 고속 유사도 검색을 위한 최적화된 인덱스 구조
  - C++로 구현되어 Python 바인딩 제공
  - 메모리 효율적인 압축 알고리즘 적용 가능
- **용도**: 벡터 간 유사도 계산 및 k-최근접 이웃 검색

#### 2. **index.pkl** (Python Pickle)
- **포맷**: Python 객체 직렬화 형식
- **내용**: LangChain FAISS VectorStore 객체
- **포함 정보**:
  - 문서 저장소 (docstore)
  - 인덱스-문서 ID 매핑
  - 임베딩 모델 설정
- **보안 주의**: Pickle 파일은 임의 코드 실행 위험이 있으므로 신뢰할 수 있는 소스만 로드

#### 3. **metadata.tsv** (Tab-Separated Values)
- **포맷**: 탭으로 구분된 텍스트 파일
- **구조**: 23행 × 6열
- **컬럼 정보**:
  ```
  - index: 순번 (0-22)
  - doc_id: UUID 형식 고유 식별자
  - page: PDF 페이지 번호 (0-15)
  - source: 원본 파일명
  - content_preview: 실제 텍스트 내용
  - content_length: 문자 수 (240-698)
  ```

#### 4. **vectors.tsv** (Vector Embeddings)
- **포맷**: 탭으로 구분된 부동소수점 배열
- **구조**: 23행 × 1024열
- **특성**:
  - 각 행: 하나의 문서 청크에 대한 벡터 표현
  - 1024차원: 다국어 지원 임베딩 모델 사용
  - L2 정규화: 모든 벡터의 norm ≈ 1.0

## 💾 벡터 데이터베이스 기본 개념

### FAISS (Facebook AI Similarity Search)

#### 정의
FAISS는 Facebook AI Research에서 개발한 고성능 벡터 유사도 검색 라이브러리입니다.

#### 주요 특징
- **확장성**: 수십억 개의 벡터까지 처리 가능
- **속도**: GPU 가속 지원으로 초고속 검색
- **메모리 효율**: 다양한 압축 알고리즘 제공
- **정확도**: 근사 검색과 정확 검색 모두 지원

#### 인덱스 유형
```python
# 본 데이터베이스는 Flat Index 사용 (정확한 검색)
index = faiss.IndexFlatL2(dimension)  # L2 거리
# 또는
index = faiss.IndexFlatIP(dimension)  # 내적 (코사인 유사도)
```

### RAG (Retrieval-Augmented Generation) 파이프라인

```mermaid
graph LR
    A[사용자 질문] --> B[임베딩 변환]
    B --> C[FAISS 검색]
    C --> D[관련 청크 추출]
    D --> E[LLM 프롬프트 생성]
    E --> F[답변 생성]
```

### 벡터 검색 프로세스

1. **질의 임베딩**: 사용자 질문을 벡터로 변환
2. **유사도 계산**: FAISS를 통한 k-최근접 이웃 검색
3. **청크 검색**: 가장 유사한 k개 문서 청크 반환
4. **컨텍스트 생성**: 검색된 청크로 프롬프트 구성
5. **답변 생성**: LLM이 컨텍스트 기반 답변 생성

- ✅ 벡터 정규화 완료 (검색 성능 최적)

### 권장 설정

#### 검색 파라미터
```python

TOP_K = 3-5          # 검색할 청크 수
THRESHOLD = 0.7      # 최소 유사도 임계값
```

#### 성능 최적화
1. **하이브리드 검색**: BM25 + 벡터 검색 조합

3. **캐싱**: 자주 검색되는 질의 결과 캐싱
4. **압축**: IVF, PQ 등 압축 인덱스 검토
